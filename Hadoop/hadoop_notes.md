\# Hadoop / HDFS



\## Purpose



Hadoop/HDFS was explored as a distributed storage layer for the retail project.



\## Work Performed



\- Set up and accessed a Hadoop environment.

\- Worked with HDFS directories and file operations.

\- Attempted to upload the retail dataset into HDFS.

\- Verified HDFS path and directory handling.

\- Used HDFS as a basic distributed storage layer for the project dataset.



\## Project Role



The processed retail dataset was prepared for downstream analytical processing and Snowflake loading.



\## Scope



Hadoop/HDFS was used at a basic storage and project-integration level.

Advanced Hadoop processing was not implemented in this project.
